# `prefect_aws.microvm.server`


HTTP server for the AWS Lambda MicroVM lifecycle hooks.

## Classes

### `LifecycleHookServer` <sup><a href="https://github.com/PrefectHQ/prefect/blob/main/src/integrations/prefect-aws/prefect_aws/microvm/server.py#L31" target="_blank"><Icon icon="github" style="width: 14px; height: 14px;" /></a></sup>


Serves the MicroVM lifecycle hooks and hands the first valid `/run` request
to the thread that calls `wait_for_run_request`.

Hooks are accepted both at `/<hook>` and at
`/aws/lambda-microvms/runtime/v1/<hook>`.

#### `stop_serving` <sup><a href="https://github.com/PrefectHQ/prefect/blob/main/src/integrations/prefect-aws/prefect_aws/microvm/server.py#L82" target="_blank"><Icon icon="github" style="width: 14px; height: 14px;" /></a></sup>

```python
stop_serving(self, timeout: float = HANDLER_FINISH_TIMEOUT_SECONDS) -> None
```

Stop accepting hook requests and wait up to `timeout` seconds for the
requests in progress to finish, so that no handler thread holds a lock
when the process forks. Requests still in progress after `timeout` are
logged and left running.

**Args:**
- `timeout`: The longest time to wait for requests in progress, in seconds.
